1 Choropleth（分级着色）

按行政区对数值属性进行着色。这里使用 naturalearth_lowres 的世界国家边界（110m 简化版）， 并为每个国家生成 模拟人口密度（人/km²）。颜色越深表示密度越高（OrRd colormap）。

加载世界地图数据…
数据源：world-atlas@2 (CDN) + 模拟密度 性能：110m 简化，~177 个国家 对应 Python：gp.choropleth(gdf, hue='pop_density_km2', cmap='OrRd', k=7) 
# 1) Choropleth：世界人口密度（模拟数据）
import geopandas as gpd
import geoplot as gp
import matplotlib.pyplot as plt

world_area = world.to_crs(epsg=3857).copy()
world_area['area_km2'] = world_area.geometry.area / 1e6
world_area['pop_density_km2'] = world_area['pop_est'] / world_area['area_km2']
world_plot = world_area.to_crs(epsg=4326)

gp.choropleth(world_plot, hue='pop_density_km2', cmap='OrRd',
              k=7, linewidth=0.3, edgecolor='gray', legend=True)
plt.title('世界人口密度（按 km²） — 示例')
plt.show()

2 Polygon / Polyplot（面/边界可视化）

显示地理边界。这里使用 nybb 数据集（纽约市 5 个行政区）的 简化多边形， 并在每个多边形重心添加标签。facecolor='none' + edgecolor='black' 等价于只画边界。

数据源：nybb 简化（5 个行政区） 对应 Python：gp.polyplot(nybb, facecolor='none', edgecolor='black', linewidth=1) 
# 2) Polygon / Polyplot：NYC Borough 边界
fig, ax = plt.subplots(figsize=(8, 8))
gp.polyplot(nybb, ax=ax, facecolor='none', edgecolor='black', linewidth=1)
for idx, row in nybb.iterrows():
    c = row.geometry.centroid
    ax.text(c.x, c.y, row.BoroName, ha='center')
plt.show()

4 KDE（核密度估计）

基于点要素估计空间密度（热点图）。这里在 NYC 范围内 随机生成 N 个点， 用 Canvas 进行高斯核密度估计，颜色越深表示点越密集（Reds colormap）。

数据源：NYC bounds 内随机点 性能：Canvas 像素级 KDE 对应 Python：gp.kdeplot(points, clip=nybb.unary_union, cmap='Reds', bw_adjust=0.5) 
# 4) KDE：基于随机生成的 NYC 点样本
from shapely.geometry import Point
minx, miny, maxx, maxy = nybb.total_bounds
xs = np.random.uniform(minx, maxx, 1000)
ys = np.random.uniform(miny, maxy, 1000)
points = gpd.GeoDataFrame(geometry=[Point(x,y) for x,y in zip(xs, ys)], crs='EPSG:4326')
points = points[points.within(nybb.unary_union)].reset_index(drop=True)

gp.kdeplot(points, clip=nybb.unary_union, cmap='Reds', shade=True, bw_adjust=0.5, ax=ax)
gp.polyplot(nybb, ax=ax, facecolor='none', edgecolor='black')

5 Hexbin（六边形分箱）

把点聚合到六边形网格，每个格子的颜色表示落入的点数。这里复用 KDE 的随机点， 用 d3-hexbin 进行分箱，并叠加 NYC 行政区边界。可在 Web Mercator 投影下叠加瓦片底图。

关于本页面

本页面是 Python 项目 Wadesha/Geo 的浏览器端展示。 由于 geoplot / cartopy / contextily 依赖较重，难以直接在静态页面运行， 因此采用 模拟数据 + 采样数据 的方式复现 Notebook 中各类图表的视觉效果与交互。 真实数据计算请参考 examples/interactive_examples.ipynb。

  • 数据策略：世界地图使用 world-atlas 110m 简化版本；NYC 行政区为手工简化多边形；城市为采样坐标；KDE/Hexbin 点为客户端随机生成。
  • 性能策略：所有几何均为低分辨率版本；KDE 使用 Canvas 像素级渲染；Hexbin 使用 d3-hexbin 在浏览器端聚合。
  • 可交互：每个图表都支持参数调整（colormap、分箱数、带宽、网格大小等），可实时观察图表变化。
  • Python 源码：每节底部均附对应 Python 代码片段，与 Notebook 一致。
